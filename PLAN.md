# Gitplore — an adventure through your projects

## Core idea

A personal portfolio presented as a small, explorable 3D world. Visitors discover your projects, step through portals, and try them through working demos or custom interactions.

The world itself showcases your engineering and design skills.

## First-release experience

- **Start in your world.** Visitors arrive directly in your curated portfolio.
- **Explore freely.** Desktop navigation uses keyboard and mouse. Distinct landmarks make projects recognizable and reward exploration.
- **Step into projects.** Some destinations present existing applications; others contain interactive demonstrations built specifically for the world.
- **Find the supporting details.** Each destination explains the project and provides access to its README and source code.
- **Jump to a destination.** A project menu offers direct navigation.
- **Browse on mobile.** Phones receive a simpler project view with descriptions, visuals, and demo links.

Present existing demos within the experience where practical; otherwise provide a clear action to open them.

## Future expansion

Add the original GitHub explorer idea after the personal portfolio:

1. Enter a GitHub username.
2. Generate a world from that profile’s public repositories.
3. Explore repository information and available demos.

Custom interactions and tailored surroundings belong to curated projects. Generated worlds use reusable environments and repository content.

## Defaults and success criteria

- Start with a small selection of featured projects, including an existing application and a custom interaction.
- Exploration remains freely accessible; visitors can reach projects without completing challenges.
- A visitor can discover a project, try it, understand its purpose, and find its code.
- Verify both demo approaches, direct navigation, return navigation, and the mobile project view.
- Keep the README in German, clearly separating the first release from the later GitHub explorer. Describe the concept and visitor experience; choose the visual theme and technical stack during implementation planning.
